# 오픈마켓 주문 취합 자동화

여러 오픈마켓(10개 이상 예정)에서 다운로드한 주문서를 협력사별로 분류·취합하고,
각 협력사가 요구하는 엑셀 양식으로 자동 변환해주는 도구.

## 현재까지 파악된 협력사 양식 (6개)

`vendor_profiles/vendor_profiles.json`에 협력사별 시트 구조(헤더, 서식, 요약 수식)를 저장.
실제 고객 개인정보는 포함하지 않음 (헤더/스타일 정보만 추출).

- **위탁배송 주문서 계열** (동일한 컬럼 구조: NO/년/월/일/주문번호/상품명/옵션/배송건수/판매수량/수령인명/수령인 연락처/배송지 주소/우편번호/특이사항/비고/택배사/택배운송장)
  - 잔망두유
  - 작심랩
  - 이플코리아
  - 어플러드
- **개별 양식**
  - 안국약품 (No./주문일자/쇼핑몰명/... 형태의 플랫 테이블)
  - 해인 (주문번호/A01-받는고객/... 형태, 색상 셀 구분 있음)

## 원본(오픈마켓) 주문서 샘플

`vendor_profiles/market_samples_schema.json`에 스마트스토어로 추정되는 원본 주문서의
컬럼 구조를 저장. 실제 상품-협력사 매칭 기준은 아직 확정되지 않음.

## 다음 단계

1. 상품(코드/옵션)-협력사 매칭 기준표 확보
2. 나머지 오픈마켓 원본 주문서 샘플 확보
3. 분류·취합 스크립트 및 협력사별 엑셀 생성기 구현

# 오픈마켓 주문 취합 자동화

여러 오픈마켓(10개 이상 예정)에서 다운로드한 주문서를 협력사별로 분류·취합하고,
각 협력사가 요구하는 엑셀 양식으로 자동 변환해주는 도구.

## 현재까지 파악된 협력사 양식 (7개)

`vendor_profiles/vendor_profiles.json`에 협력사별 시트 구조(헤더, 서식, 요약 수식)를 저장.
실제 고객 개인정보는 포함하지 않음 (헤더/스타일 정보만 추출).

- **위탁배송 주문서 계열** (동일한 컬럼 구조: NO/년/월/일/주문번호/상품명/옵션/배송건수/판매수량/수령인명/수령인 연락처/배송지 주소/우편번호/특이사항/비고/택배사/택배운송장)
  - 잔망두유
  - 작심랩
  - 이플코리아
  - 어플러드
- **개별 양식**
  - 안국약품 (No./주문일자/쇼핑몰명/... 형태의 플랫 테이블)
  - 해인 (주문번호/A01-받는고객/... 형태, 색상 셀 구분 있음)
  - 벤더명 미정 (`vendor_profiles/vendor7_profile_pending_name.json`) — 원본 주문서를 이 양식대로 가공한 샘플. 결제번호/채널상품번호/톡딜여부/도서산간 등 49개 컬럼을 그대로 유지하는 구조. 샘플 상품 브랜드: 마더네스트.

## 상품→협력사 매칭 규칙

상품명/브랜드명 기준으로 협력사를 판별한다 (사용자 확정). 브랜드 키워드 매핑표는
아직 미완성 — 확인 필요:

- 잔망두유 → "잔망두유"
- 작심랩 → "작심랩"
- 어플러드 → "어플러드"
- 이플코리아 → ? (샘플 상품 브랜드 "데이너프", 확인 필요)
- 해인 → ? (샘플 상품 브랜드 "햇살듬뿍", 확인 필요)
- 안국약품 → ? (샘플 상품이 비타민D/칼마디/브이팩/애사비젤리 등 여러 브랜드 혼재 — 단일 키워드로는 불가능해 보임, 목록 필요)
- 벤더명 미정(파일7) → ? (샘플 상품 브랜드 "마더네스트", 벤더명 자체도 확인 필요)

## 다음 단계

1. 위 브랜드 키워드 매핑표 확정 (벤더별 브랜드명 목록, 특히 안국약품처럼 다브랜드인 경우)
2. 나머지 오픈마켓 원본 주문서 샘플 확보 (10개 이상 마켓 예정)
3. 분류·취합 스크립트 및 협력사별 엑셀 생성기 구현
